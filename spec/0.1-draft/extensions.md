# Prooflane Extension Registry (v0.1 Draft)

This registry tracks optional keys and profiles. Use reverse-DNS style identifiers.

- Namespace `x:` is reserved for private experiments.
- Profiles MAY add capabilities without breaking PLA-Core.

## Reserved Keys

- security.trustchain (core)
- security.policies (core)
- search.embeddings (core)
- search.chunks (core)
- search.meta (core)

## Known Extensions (Informative)

- x.citations (draft)
- x.attachments (draft)
- x.prov (draft)
